# برنامه‌ریزی و گزارش پیشرفت پروژه فودینو (Foodino)

## معرفی پروژه

فودینو یک اپلیکیشن سفارش غذا است که با استفاده از React و Vite توسعه داده می‌شود. هدف پروژه، نمایش فهرست غذاها، مدیریت سبد خرید، محاسبه مبلغ سفارش و ثبت اطلاعات مشتری است.

در توسعه این پروژه از مفاهیمی مانند Components، Props، Context API، useReducer و JSON Server استفاده شده است.

## راهنمای تکمیل جدول

- **زمان تخمینی:** مدت‌زمان پیش‌بینی‌شده برای انجام کامل هر فعالیت در برنامه اولیه.
- **زمان واقعی:** مدت‌زمان تقریبی صرف‌شده برای فعالیت تا پایان ۲۶ مهر ۱۴۰۵.
- **وضعیت:** انجام‌شده، نیمه‌کاره یا انجام‌نشده.
- **یادداشت:** توضیح کوتاه درباره نتیجه فعالیت و کارهای باقی‌مانده.

زمان‌های واقعی در بازه‌های تقریبی ثبت شده‌اند و زمان آموزش جدا از کار عملی محاسبه می‌شود.

زمان‌های مربوط به روز ۲۶ مهر تخمینی هستند. فعالیت‌های این روز در ردیف‌های مرتبط جدول اصلی ثبت شده‌اند تا تعداد ردیف‌های برنامه‌ریزی تغییر نکند.

### گزارش روز ۲۶ مهر ۱۴۰۵

**نام پروژه:** Foodino – اپلیکیشن سفارش غذا

**فناوری‌های مورد استفاده:** React، Vite، Git، GitHub، VS Code و Chrome Debugger

#### شرح فعالیت‌های روز ۲۶ مهر

در این روز، ابتدا وضعیت شاخه‌های Git و تغییرات پروژه Foodino بررسی شد. همچنین Pull Requestهای ثبت‌شده در GitHub مورد بررسی قرار گرفتند. مشخص شد که دو Pull Request قبلی ادغام شده‌اند، اما Pull Request مربوط به قابلیت سبد خرید همچنان باز است.

در ادامه، هنگام بررسی ادغام شاخه feature/cart با dev، مشکل Merge Conflict در فایل project-plan.md شناسایی شد. برای جلوگیری از حذف اطلاعات گزارش‌های قبلی، رفع این تداخل به مرحله بعد موکول شد.

سپس مستندات پروژه بررسی شدند و ساختار برنامه برای ارائه مرور شد. در این بخش، وظایف کامپوننت‌های Header، Meals، MealItem، Cart و Checkout و نحوه استفاده از Context API، useReducer و JSON Server بررسی شد.

بخش دیگری از فعالیت‌های روز به راه‌اندازی قابلیت Debug در VS Code اختصاص داشت. تنظیمات فایل launch.json بررسی شد و برای شناسایی علت متوقف نشدن برنامه روی Breakpoint، مسیر فایل‌های React و تنظیمات Source Map مورد بررسی قرار گرفت.

همچنین مشکل نمایش ظاهری فرم Checkout بررسی شد و مشخص شد که هماهنگی فایل JSX و استایل‌های CSS نیاز به بررسی بیشتری دارد.

در پایان روز، مشکل Debugger هنوز به‌طور کامل برطرف نشده بود و بررسی Pull Request مربوط به سبد خرید نیز ادامه داشت.
