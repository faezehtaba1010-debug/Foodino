# برنامه‌ریزی و گزارش پیشرفت پروژه فودینو

## راهنمای تکمیل جدول

- **زمان تخمینی:** مدت پیش‌بینی‌شده برای انجام کار، بدون زمان استراحت.
- **زمان واقعی:** مدت زمانی که واقعاً روی آن فعالیت کار کرده‌ام؛ تا قبل از انجام کار با «—» مشخص می‌شود.
- **وضعیت:** `انجام نشده`، `در حال انجام` یا `انجام شده`.
- **یادداشت:** نکات فنی، مشکلات، نتیجه تست یا شماره Commit.
- زمان‌ها بر حسب ساعت هستند و در صورت نیاز تخمین‌ها قابل بازنگری‌اند.
