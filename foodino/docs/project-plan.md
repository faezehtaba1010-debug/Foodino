### شرح فعالیت‌های روز ۲۵ مهر

در این روز، بخش‌های اصلی رابط کاربری Foodino توسعه داده شدند. کامپوننت‌های Header، Meals و MealItem تکمیل شدند و نمایش اطلاعات غذاها با استفاده از Props و map پیاده‌سازی شد.

سپس مدیریت سبد خرید با Context API و useReducer انجام شد. قابلیت نمایش اقلام سبد خرید و محاسبه مبلغ کل سفارش نیز تکمیل شد.
