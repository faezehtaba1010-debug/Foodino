# برنامه‌ریزی و گزارش پیشرفت پروژه فودینو (Foodino)

## معرفی پروژه

فودینو یک اپلیکیشن سفارش غذا است که با استفاده از React و Vite توسعه داده می‌شود. هدف پروژه، نمایش فهرست غذاها، مدیریت سبد خرید، محاسبه مبلغ سفارش و ثبت اطلاعات مشتری است.

در توسعه این پروژه از مفاهیمی مانند Components، Props، Context API، useReducer و ارتباط با API استفاده شده است. در مراحل اولیه، JSON Server برای مدیریت داده‌های آزمایشی به کار گرفته شد و در ادامه، توسعه Backend مستقل با Node.js و Express و استفاده از دیتابیس SQLite آغاز شد.

## راهنمای تکمیل جدول

- **زمان تخمینی:** مدت‌زمان پیش‌بینی‌شده برای انجام هر فعالیت در برنامه اولیه.
- **زمان واقعی:** مجموع زمان تقریبی صرف‌شده برای هر فعالیت تا پایان ۲۹ مهر ۱۴۰۵.
- **وضعیت:** انجام‌شده، نیمه‌کاره یا انجام‌نشده.
- **یادداشت:** توضیح کوتاه درباره نتیجه فعالیت و کارهای باقی‌مانده.

زمان‌های واقعی تقریبی هستند و زمان آموزش جدا از کار عملی محاسبه می‌شود.

فعالیت‌های جدید مربوط به Backend و SQLite در ردیف‌های مرتبط جدول اصلی ثبت شده‌اند تا ساختار ۲۴ ردیفی برنامه حفظ شود.

تا این مرحله، بخش‌های اصلی رابط کاربری Foodino شامل نمایش غذاها، مدیریت سبد خرید، تغییر تعداد اقلام و محاسبه مبلغ کل پیاده‌سازی شده‌اند.

Backend پروژه با استفاده از Node.js و Express ایجاد شده و دیتابیس SQLite برای نگهداری اطلاعات غذاها و سفارش‌ها به پروژه اضافه شده است.

دریافت اطلاعات غذاها از SQLite از طریق API بررسی و تأیید شده است. همچنین کامپوننت مشترک Button ساخته شده و خطاهای شناسایی‌شده در اجرای Backend و نمایش کارت‌های غذا برطرف شده‌اند.

بااین‌حال، **فرایند ذخیره‌سازی سفارش‌ها در SQLite هنوز به نتیجه قطعی نرسیده و نیازمند بررسی و تست مجدد است.**

فعالیت‌های باقی‌مانده شامل بررسی خطای ارسال سفارش، تست مجدد مسیر POST /orders، تکمیل مدیریت خطا و اعتبارسنجی فرم Checkout، بازبینی Modal، بررسی نهایی نمایش در موبایل و دسکتاپ، پیاده‌سازی Hook مشترک درخواست HTTP، تمرین Form Actions و تست نهایی پروژه است.

همچنین لازم است وضعیت تغییرات Git و Pull Request مربوط به SQLite بررسی و مستندات پروژه پس از تأیید عملکرد نهایی به‌روزرسانی شوند.
