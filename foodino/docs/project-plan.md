# برنامه‌ریزی و گزارش پیشرفت پروژه فودینو (Foodino)

## معرفی پروژه

فودینو یک اپلیکیشن سفارش غذا است که با استفاده از React و Vite توسعه داده می‌شود. هدف پروژه، نمایش فهرست غذاها، مدیریت سبد خرید، محاسبه مبلغ سفارش و ثبت اطلاعات مشتری است.

در توسعه این پروژه از مفاهیمی مانند Components، Props، Context API، useReducer و JSON Server استفاده شده است.

## راهنمای تکمیل جدول

- **زمان تخمینی:** مدت‌زمان پیش‌بینی‌شده برای انجام کامل هر فعالیت در برنامه اولیه.
- **زمان واقعی:** مدت‌زمان تقریبی صرف‌شده برای فعالیت تا پایان ۲۵ مهر ۱۴۰۵.
- **وضعیت:** انجام‌شده، نیمه‌کاره یا انجام‌نشده.
- **یادداشت:** توضیح کوتاه درباره نتیجه فعالیت.

زمان‌های واقعی در بازه‌های ۱۵ دقیقه‌ای ثبت شده‌اند و زمان آموزش جدا از کار عملی محاسبه می‌شود.

### گزارش روز ۲۵ مهر ۱۴۰۵

**نام پروژه:** Foodino – اپلیکیشن سفارش غذا

**فناوری‌های مورد استفاده:** React، Context API، useReducer، JSON Server و Git

#### شرح فعالیت‌های روز ۲۵ مهر

در این روز، توسعه بخش‌های اصلی رابط کاربری Foodino ادامه پیدا کرد. کامپوننت‌های Header، Meals و MealItem تکمیل شدند و نمایش اطلاعات غذاها با استفاده از Props و map پیاده‌سازی شد.

دریافت اطلاعات غذاها از API نیز انجام شد. همچنین قابلیت قالب‌بندی قیمت‌ها تکمیل شد و بخشی از مدیریت وضعیت بارگذاری و خطای درخواست‌ها پیاده‌سازی شد.

در ادامه، مدیریت سبد خرید با Context API و useReducer انجام شد. نمایش اقلام سبد خرید و محاسبه مبلغ کل سفارش نیز تکمیل شدند.

سپس کار روی پنجره Modal، فرم Checkout، اعتبارسنجی اطلاعات مشتری و ارسال سفارش به JSON Server ادامه پیدا کرد. این بخش‌ها در پایان روز همچنان نیمه‌کاره بودند.
